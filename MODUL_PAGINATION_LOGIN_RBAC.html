Modul Implementasi: Pagination, Login & RBAC

Project: belajar-laravel (Simulasi Penjadwalan Kuliah)

Stack: Laravel 12 · PHP 8.2 · MySQL · spatie/laravel-permission 6.x

Tanggal: 3 Oktober 2026

Pendahuluan

Modul ini menambahkan tiga fitur pada aplikasi CRUD penjadwalan kuliah yang sudah ada:

  1. Seeder data mahasiswa — membuat kelas ase11 dan ase12, lalu mengisi masing-masing 25 mahasiswa (total 50 data) agar pagination terlihat nyata.
  2. Pagination sederhana pada tabel mahasiswa — 10 baris per halaman, tanpa framework CSS tambahan.
  3. Login + RBAC dengan package spatie/laravel-permission — semua halaman wajib login; role admin bisa CRUD penuh, role mahasiswa hanya bisa melihat data (read-only).

Prinsip yang dipakai: fokus pada fungsi, tampilan sederhana dan rapi. Setiap view tetap berupa halaman HTML mandiri yang memakai CSS bersama melalui @include('partials.style'), mengikuti pola proyek yang sudah ada.

Langkah Implementasi

1. Install package RBAC (Spatie)

Jalankan perintah berikut di root proyek:

composer require spatie/laravel-permission

Versi 8.x membutuhkan PHP 8.3; karena environment memakai PHP 8.2, Composer otomatis memasang versi 6.25.0 yang kompatibel dengan Laravel 12.

Lalu publish config dan migration-nya:

php artisan vendor:publish --tag=permission-config
php artisan vendor:publish --tag=permission-migrations

Hasilnya: config/permission.php dan migration database/migrations/2026_10_03_014705_create_permission_tables.php.

public function showLoginForm(): View
{
    return view('auth.login');
}

public function login(Request $request): RedirectResponse
{
    $credentials = $request->validate([
        'email'    => ['required', 'email'],
        'password' => ['required'],
    ]);

    if (Auth::attempt($credentials, $request->boolean('remember'))) {
        $request->session()->regenerate();
        return redirect()->intended(route('mahasiswa.index'));
    }

    throw ValidationException::withMessages([
        'email' => ['Email atau password salah.'],
    ]);
}

public function logout(Request $request): RedirectResponse
{
    Auth::logout();
    $request->session()->invalidate();
    $request->session()->regenerateToken();
    return redirect()->route('login');
}

5. Atur route: login + proteksi RBAC

File: routes/web.php Updated

// Route login (hanya tamu)
Route::middleware('guest')->group(function () {
    Route::get('/login', [AuthController::class, 'showLoginForm'])->name('login');
    Route::post('/login', [AuthController::class, 'login']);
});
Route::post('/logout', [AuthController::class, 'logout'])
    ->middleware('auth')->name('logout');

// KHUSUS ADMIN (create, store, edit, update, destroy)
Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::resource('mahasiswa', MahasiswaController::class)->except(['index', 'show']);
    // ... resource lainnya
});

// SEMUA USER LOGIN (read-only: index & show)
Route::middleware('auth')->group(function () {
    Route::resource('mahasiswa', MahasiswaController::class)->only(['index', 'show']);
    // ... resource lainnya
});
Penting (urutan route): grup role:admin didaftarkan lebih dulu agar route create (mahasiswa/create) terdaftar sebelum route show (mahasiswa/{mahasiswa}). Jika tidak, GET mahasiswa/create akan ditangkap route show dengan parameter {mahasiswa} = "create".

Struktur Tabel RBAC (Spatie)

TabelFungsi
rolesDaftar role (admin, mahasiswa).
permissionsDaftar permission (lihat/tambah/ubah/hapus-data).
model_has_rolesRelasi user ↔ role.
model_has_permissionsRelasi user ↔ permission (langsung).
role_has_permissionsRelasi role ↔ permission.

Pada modul ini pembatasan akses route memakai role (role:admin), sedangkan permission tetap dibuat dan di-assign ke role sebagai contoh konsep RBAC yang bisa dikembangkan lebih lanjut (mis. permission:tambah-data).

  1. Buka /mahasiswa tanpa login → otomatis diarahkan ke /login.
  2. Login sebagai admin → masuk ke /mahasiswa: tombol Tambah/Ubah/Hapus tampil, pagination muncul (10 data per halaman), akses /mahasiswa/create berhasil (200).
  3. Logout, lalu login sebagai mahasiswa → tombol Tambah/Ubah/Hapus hilang (kolom Action berisi “-”), pagination tetap tampil, akses /mahasiswa/create ditolak (403).
  4. Klik Logout → kembali ke halaman login.
